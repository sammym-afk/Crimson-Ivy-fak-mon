CRIMSON IVY — PLAYABLE STARTER PROTOTYPE

FILES
- index.html
- style.css
- game.js

HOW TO PLAY
1. Put all three files in the same GitHub repository.
2. In GitHub Pages, publish from the main branch and the root folder.
3. Open the GitHub Pages link in Safari.

CONTROLS
- Arrow keys or WASD: move
- Space/Enter or A button: interact
- M or MENU button: open the Crimson Phone

WHAT IS INCLUDED
- Starter's Meadow and part of Ivy Town
- Professor Ivy
- Pokémon Center
- Poké Mart
- Party, Bag, Pokédex, Map, Quest Log, and Save menus
- Touch controls for iPad
- Local save data

IMPORTANT
This is a playable prototype, not the entire finished 200-Pokémon RPG. A complete game would need many more maps, stories, battles, Pokémon data, artwork, music, and DLC content.
